当前推荐 CLI 配合 GPT-6.1 Sol 或能力更强的模型。应用内原生 Agent 与 DeepSeek 的复杂任务表现仍不稳定。

当前正式版为 App 0.46.0-r20，配套数据库 db-7.2.50-r6。下载及校验值以发行页实际提供的附件为准。本阶段 Windows 程序不做代码签名。
