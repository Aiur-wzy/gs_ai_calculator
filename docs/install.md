# 安装与获取数据库

## 安装正式版

当前版本是 App **1.0.4**（发行工件 `app-1.0.4-r2`），配套数据库为 **db-7.2.54-r1**。支持 Windows 10/11 x64。请以[应用发行页](https://github.com/Aiur-wzy/gs_ai_calculator/releases)和[数据库发行页](https://github.com/Aiur-wzy/gs_ai_calculator_db/releases)实际提供的附件和 SHA-256 校验值为准。仓库源码 ZIP 不包含 EXE 或完整数据库。

1. 从[官方下载页](https://aiur-wzy.github.io/gs_ai_calculator/)下载 Windows 小安装器，解压后运行 `GenshinCalcSetup.exe`。
2. 点击「浏览…」选择安装目录。默认位置是 `%LOCALAPPDATA%\GenshinCalcStable`，也可以在其他盘选择空目录。程序和数据库分别存放在所选目录下的 `app` 和 `data`。
3. 选择「安装程序和数据库（推荐）」即可安装完整组合。选择「只安装程序，稍后下载数据库」可先装应用，随后在 GUI 中选择「下载数据库」。安装会验证签名清单和下载文件。
4. 安装完成后，在 Windows 开始菜单搜索「原神拉表」。首次正式安装使用新的资料目录。旧开发版作为历史参考，自己保留的独立方案可按需在新版打开。

小安装器和 App EXE 未做 Windows 代码签名。Windows 可能显示发布者或安全提示，请根据发行页核对下载来源和 SHA-256 校验值。安装时，项目的更新索引仍须通过签名验证。

## 程序包、便携版与打开方案

发行页的独立 App ZIP 供小安装器、更新及离线安装使用。此文件缺少数据库及便携启动所需的目录标记。若另有完整便携包，请解压整个目录。便携版直接使用同目录的 `app` 和 `data`，会话和设置也写入本包的资料目录。

如果只安装了程序，可在 GUI 中按提示下载或补装配套数据库。离线补装时，在下载页的「兼容组合与离线补装」选择与已安装程序版本对应的签名清单，再配合数据库包使用。

当前推荐由 GPT-6.1 Sol 或更高能力模型通过 CLI 完成排轴和计算，再用 GUI 打开方案、人工看图审核。应用内原生 Agent 与 DeepSeek 在复杂任务中仍不稳定。参见 [CLI 工作流](cli-workflow.md)。

`GenshinCalc.exe` 是 CLI，`GenshinCalcGUI.exe` 是图形界面。在安装目录或便携版的 `app` 子目录打开 GUI，然后从文件菜单选择原生方案。也可以在该 `app` 目录运行以下命令。需要重算时，请在应用中主动执行计算。

```powershell
.\GenshinCalcGUI.exe gui --open 'D:\my-task\native.plan.json'
```

图形界面和 CLI 使用同一套领域服务。查看图形时还应核对当前文件、数据库版本、计算状态和近似说明。只有聊天文字或一个能打开的草稿，不能证明完整计算已经通过。

## 离线安装和后续更新

- 要完整离线安装，从[官方下载页](https://aiur-wzy.github.io/gs_ai_calculator/)下载并解压 `GenshinCalc-1.0.4-r2-full-offline-windows-x64.zip`。运行包内的 `GenshinCalcSetup.exe`，选择安装目录，再点击「使用离线发行包」，依次选择包内的 `latest.json`、App ZIP 和数据库包。分开下载这三个文件时也可按相同步骤安装。
- 在线更新会列出通过验签且与已装版本兼容的组合。可选范围随发行变化，可能包含仅更新程序、仅更新数据库或同时更新。
- 在 Windows「设置」→「应用」→「已安装的应用」中找到「原神拉表」，选择卸载。也可在开始菜单搜索「卸载原神拉表」。卸载会删除程序和数据库，界面可选择「保留我的方案、聊天和设置」。另存到安装目录外的方案由用户自行管理。

## 旧正式版同库升级与更新恢复

下列操作适用于通过旧版 Setup 安装的正式版。下载页和签名发布索引列出当前可用的升级组合。[官方下载页](https://aiur-wzy.github.io/gs_ai_calculator/)

1. 已安装 1.0.3 并使用 db-7.2.52-r1 时，在 App 检查更新，先选择「更新程序」。更新前关闭 App、CLI 和其他更新器。本次保留数据库和个人资料。
2. 打开 1.0.4，再次检查更新并确认下载 db-7.2.54-r1。完成后再次检查应显示已是最新。全新安装可以直接安装 1.0.4 和配套数据库。
3. 更早的正式版先按各版签名索引提示升级。仅安装程序的用户可以先在「资料库」补装配套数据库，然后按更新提示继续。

更新中断后，直接打开新版 Setup，按界面提示处理：

- 「清理尚未执行的更新」先核对当前安装，再清理上次准备的暂存文件。现有 App、数据库和用户资料全部保留。完成后重新打开 Setup，即可重新检查升级或卸载。
- 「恢复上次更新」会根据已验证的提交记录恢复原组合，或为已经提交的组合完成清理。恢复前会显示原版本组合、目标组合和操作编号，并要求确认。
- 有未收尾的更新时，Setup 会暂缓卸载和重装。若旧安装器已移除程序且新版无法恢复，请保留资料目录和更新记录，并记录错误码和操作编号。

普通 CLI 查询和计算无需在 App 内配置 DeepSeek Key。数据库可能收录未上线、测试、废弃和状态未知的条目，采用未上线或未知实体前需要确认。详见[数据声明](data-notice.md)。
