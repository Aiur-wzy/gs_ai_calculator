# 按需披露、资料缓存与上下文恢复

先取当前决定所需的资料和结果，再按需查细节。各工作卡提供阅读建议，访问、编辑和计算按[实际工作法](index.md)和当前工具合同执行。

## 小入口与小资源

先读当前候选摘要及相关工作卡。能力和字段从实际目录定向取得。角色确定后按[附录配方](../data/character-appendices.md)发现并读完可读正文。其他资料依当前问题取。用 `gs_read_skill {}` 发现捆绑资源，按 `resource` 和实际 `next_offset` 读取所需页。同一资料内容可用 `content_hash` 核对。

| 当前问题 | 优先读取 |
|---|---|
| 首次采用／新增角色 | 角色附录导航、approved／pending各分类正文及采用摘要；同快照已读正文复用 |
| 配装／面板 | 身份、等级命座、武器套装、基础值／成长及面板口径 |
| 动作 | 用户动作串、变体、前后台、连段窗口及关键时点 |
| 事件 | 当前动作及相关天赋／命座／装备派生、附着与生命周期 |
| 数值 | 具体节点的倍率、GU／ICD、来源、采样与执行绑定 |
| 计算问题 | 短诊断、首个阻断、受影响ID及精确记录页 |

为后续要用的资料保留版本、来源位置、采用结论和资源 ID。App 查询正文可复用；文件权限允许时，也可在任务目录保存原文与采用摘要。返回引用、下一页或转存文件时沿实际入口读取。用户需要的完整来源和结果保留为可访问资料或文件，按要求给出明细。默认答复先给关键数值、执行范围、首个失败和证据入口。

原文与自己的解释分开保存。实际查询提供 `notebook_ref` 时可以读取无损小档，再填写触发、受益者、持续/刷新、单位、取样和采用位置；没有被读取的段落不能写成“已确认没有效果”。多条件任务用[任务对照](task-evidence.md)保留原题和未解决差异，避免压缩后只剩下一份过度简化的目标摘要。

同一快照的正文可复用，记录事实、状态、版本、采用或待核原因及对应输入。导航 `complete` 说明枚举范围完成，正文仍按实际读取范围记录。来源保持原状态，正式使用前按当前输入、资料身份和必要批准核验。

## DSH Surface与跨轮

DSH管理同一持久Session、消息、raw reasoning、工具历史、压缩与checkpoint；不另造App消息历史或Skill已读代际。DSH Surface代际由DSH管理；Skill读取只承诺实际content_hash、offset、delivered_chars、next_offset等分页字段，不额外签发已读代际回执。

代际变化表示压缩／裁剪可能改变可见正文，不撤销访问权、不自动使资料失效。所需文字还在就复用；不在则沿角色小资源索引只补当前决定所需精确页面，不全量重读。资源manifest是有界最近列表，不保证找回全部旧资源；在工件索引／finding里保留后续要用的稳定ID。必读正文不可恢复时报告并定向补读，不能把一份旧摘要冒充仍掌握所有精确字段。

续接所需记录包括当前输入修订、用户固定项与数量约束、已确认结论、未验证范围、来源位置和下一项工作。恢复时先核当前候选，再补当前决定所需的记录。对结果未知的写入先确认状态。

## 修订与失效

- 面板改变：重算受影响数值与资源结果；动作和角色原文不必重读。
- 武器／套装／命座／天赋改变：重新盘点相关来源、节点和绑定。
- 动作微调或大改：遵守用户授权，保留稳定ID或显式映射，复核后继时点、附着、资源及绑定；focus可以不变，不要求回退后才允许修改。
- DB／App身份不兼容：不重签旧候选或回执；旧资料和聊天可只读，用户可用兼容prompt在新任务重建意图。正常问答／独立研究不因旧执行资格失效而锁死。

短回执说明事实与可恢复入口，不输出writer fence、凭据或整份trace。每轮正式答复与可折叠推理／活动分开；DSH原生思考可按其持久化／展示规则保留，不复制到业务草稿。
