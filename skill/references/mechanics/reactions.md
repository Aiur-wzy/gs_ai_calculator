# 元素反应、附着与 ICD

> 适用：涉及反应伤害的计算、反应覆盖率估算、排轴中的附着安排。
> 与 damage-formula.md 的关系：本文细化反应触发机制（附着、ICD、覆盖率）；**伤害公式以 damage-formula.md 为准**（含月曜/星烁新反应体系）。

## 一、反应分类速查

| 类别 | 反应 | 伤害特征 |
|---|---|---|
| 增幅（乘算） | 蒸发、融化 | 直接放大本次伤害，吃攻击/倍率/增伤/暴击 |
| 激化 | 原激化（状态）、超激化（雷触发）、蔓激化（草触发） | 基础伤害区加算，吃增伤/暴击 |
| 剧变（固定） | 超载、超导、感电、碎冰、扩散、绽放/超绽放/烈绽放、燃烧 | 只与角色等级、精通、目标抗性有关 |
| 月曜 | 月感电、月绽放、月结晶 | 新伤害类型：不吃传统增伤、无视防御、可暴击，含精通反应增伤区 |
| 星烁 | 星超导、星扩散 | 新伤害类型：同上，另含叠层/风旋等级机制 |
| 状态 | 冻结等 | 状态本身不等同一条伤害，但会影响元素底与效果条件；不能因为无直接伤害就省略其机制 |

## 二、增幅反应（蒸发 / 融化）

```
反应系数 = 基础倍率 × (1 + 精通加成 + 反应伤害加成)
```

- **基础倍率**：水打火 / 火打冰 = 2.0；火打水 / 冰打火 = 1.5（克制方正向 2.0，反向 1.5）。
- **精通加成**：`精通加成 = 2.78 × EM / (EM + 1400)`（EM=触发者的元素精通）。1000 精通约 115.8%。
- **反应伤害加成**：来自圣遗物套装（如魔女 4 件）、特定 buff，与精通加成加算。
- 只有**触发者**的精通与反应加成生效，附着提供者的面板无关。

## 三、激化反应

- **原激化**：草+雷命中后为目标附加激化状态（持续若干秒），期间雷伤触发超激化、草伤触发蔓激化。
- **激化加成（基础伤害区加算）**：

```
激化加成 = 等级基数 × 反应系数 × (1 + 精通加成 + 反应伤害加成)
```

  - 等级基数：90 级约 1446.85（随角色等级成长，查表）。
  - 反应系数：超激化 1.15，蔓激化 1.25。
  - 精通加成：`5 × EM / (EM + 1200)`。
- 激化加成加在基础伤害区（`有效攻击 × 倍率 + 激化加成`），因此**低倍率多段技能从激化获益比例更高**。
- 激化加成可暴击、吃增伤、吃目标防御/抗性。

## 四、剧变反应（固定伤害）

```
剧变伤害 = ( 等级基数 × 反应倍率 × (1 + 精通加成 + 反应伤害加成) + 剧变羽毛区 ) × 抗性承伤
```

- **与攻击、倍率、传统增伤、暴击、防御完全无关**；只吃触发者等级、精通、反应加成与目标抗性。
- 精通加成：`16 × EM / (EM + 2000)`。
- **反应倍率**（V5.2 增强后）：燃烧 0.25 / 扩散 0.6 / 超导 1.5 / 感电 2.0 / 绽放 2.0 / 超载 2.75 / 碎冰 3.0 / 烈绽放·超绽放 3.0。
- **等级基数（反应基础值）**：70 级 765.64 / 80 级 1077.44 / 90 级 1446.85 / 95 级 1561.46 / 100 级 1674.81。**等级对剧变收益极大**，主玩剧变的角色优先拉满等级。
- 扩散伤害可继续触发增幅反应（乘增幅系数）。

## 四之二、月曜与星烁机制

伤害公式见[伤害体系](damage-formula.md)。有对应资格时，月感电替换水雷反应并建立持续雷暴云；每跳的实际贡献者受扣量前正残量和最近五秒施加窗口约束，同一提供者去重后分别判暴击再加权。月绽放建立草原核与草露，消费资源本身不自动等于一条能力直伤。月结晶由岩水产生月笼，每三次反应结算谐奏，不能套普通结晶一秒晶片公共冷却。

月绽放涉及草露替代、草核转化或持续效果重施时，先核对所用角色的[附录正文](../data/character-appendices.md)，再核对以下事实。

- 可替代资源分别保留取得条件、上限、余额和到期。按实际消费顺序取够可用量，耗露伤害、层数及后续收益都以同一次实际扣量为准。
- 一颗草核只有一份状态。转换前已发生的爆炸按原规则计入；转换后的普通核退出原爆炸和场上上限处理。按转换条件、范围和生效时段检查新旧核，再查替换核的吸收、层数和失效。
- 持续效果重施时分别核对原实例是否仍生效、累计是否保留、攻击节奏是否继续，以及触及阈值或真正到期后如何清除。证据只确认保留累计时，攻击相位和命中偏移仍按独立资料核实。

星超导由冰雷方向建立领域/层数，能力直伤使用最近完成的四秒结算：基础系数零层为1，1～12层为1.4＋0.05×层数，大于12层为2。不能把反应触发本身再算一份能力直伤。

星扩散按风旋等级区分冰/风分项。风分项第一权重0.6属于本次风触发者；冰分项第一权重0.6取最高冰附着贡献者，第二权重0.3取最高风触发贡献者，其余按实际分项伤害选择。资格提供者和伤害贡献者不同，角色槽证据不可用全队统一排序替代。伤害后的冰附着影响后继，不追溯改变本次伤害。

月曜/星烁不吃传统增伤、无视防御、可暴击。能力直伤不因名称含反应就附着，也不参与多人反应权重。同一伤害方式转化属于替换；独立新组件才额外计入。App输入、支持范围与资格查询单独见[星月适配](../app-mechanics/elements/special-reactions.md)。

## 五、元素附着与元素量

- 伤害元素、附着尝试与实际附着分开；一次元素伤害可以因 ICD 不附着，无伤害动作也可能附着。先查本次技能/变体的元素量（U）与附着条件，不默认所有命中都是 1U。
- 普通元素底有附着税、衰减和刷新规则，不能按一个通用“秒/U”常数推全场，也不能将重复附着简单相加。反应时先计算已有元素底的自然衰减，再按具体反应规则消耗；触发元素有剩余不代表一定立刻变成新的元素底。
- 元素共存、冻结/激化等反应状态、护盾与原生元素目标须分别处理；风、岩不按普通持续元素底记录。查不到规则时区分未知与已知无附着，保留受影响事件。

机制依据：[KQM 元素量理论](https://library.keqingmains.com/combat-mechanics/elemental-effects/elemental-gauge-theory)，核对于 2026-09-13；具体角色元素量和例外仍需对应版本资料。这里提供读状态的原则，不是可直接执行的完整反应规则表。

## 六、ICD（附着内置冷却）

- 标准计时窗口2.5秒、命中间隔通常三次：第1、4、7…次可附着。计数放行不重置2.5秒计时器；计时窗口重置会重置计数，不能实现成任一条件满足就同时清两者。
- 规则按实际来源角色、共享计数身份和目标确定；规则模板与共享计数身份不是同一概念。普攻/重击/下落/E/Q分类不足以推断共享或独立，初段/持续/终结和命座追加分量都要逐一查证。
- 有据的特殊每X命中沿同一计时计数原理调整；只有证据证明某接触根本不尝试附着时才增加前置接触条件，不能把两层条件无意相乘。无ICD、已知无附着与资料未知分别表达。
- 有限二元序列不能因重复图样无限外推；命中、附着尝试、通过ICD和反应成立分别核对。被ICD阻止的元素伤害仍可造成伤害；允许附着但无可反应元素底时也不发生反应。
- 具体元素量、共享范围、时点和特殊重置先查本地原文及固定版本资料；不足时定向外查并保留来源、采用与未采用结论、未解决项，不能从缺资料推断无ICD。

机制依据：[KQM ICD](https://library.keqingmains.com/combat-mechanics/internal-cooldown)。实际字段和局部适配见[元素输入](../app-mechanics/elements/runtime.md)。

## 七、附着顺序与实战要点

- 普通增幅反应通常由后手有效附着触发，使用触发者面板；周期反应与多提供者体系的归属另按机制确认。记录“哪次附着触发、使用谁的面板、在哪一时点取样”。
- 无附着残留提示：强附着抵消弱附着后可能无残留（如 2U 遇 1U 克制消耗），排轴时避免"挂不上"的空转。
- 多元素共存时，按已验证的反应优先级、消耗和子事件规则处理，不能对每个元素底独立扣一遍。复杂内部触发链不确定时列为未支持或情景近似。

逐跳先判附着资格，再按命中前元素底、消耗和反应归属计算；预期反应与实际状态分开核对。App与旧数值入口区别见[元素适配](../app-mechanics/elements/runtime.md)。

## 八、快速检查清单

1. 本次伤害触发什么反应？增幅 / 激化 / 剧变走对应分支，别套错公式。
2. 谁是触发者？用谁的面板/精通？
3. 增幅反应方向对不对（1.5 还是 2.0）？
4. 该分量的附着方式有证据吗？ICD是否允许本次附着？未知项是否保持未验证？
5. 剧变反应是否误用了攻击/增伤/暴击？（不能）
6. 激化加成放对位置了吗？（基础伤害区加算，不是独立乘区）
