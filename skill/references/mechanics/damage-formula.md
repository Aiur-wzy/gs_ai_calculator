# 伤害公式与乘区体系

> 适用：所有伤害计算的基础。
> 伤害分三大体系——**传统直伤 / 剧变反应 / 月曜·星烁反应**，公式结构不同，先判定伤害类型再套公式。
> 本页提供概念公式和结构说明，不是新版本事实或工具schema的替代。实际计算保留来源/单位/精度并解释差异；不能用统一误差比例豁免错误，或把粗估假设当作正式数值依据。

## 零、伤害类型判定（计算第一步）

| 体系 | 判定 | 结构特征 |
|---|---|---|
| 传统直伤 | 普通技能伤害，可触发蒸发/融化/激化 | 吃传统增伤（元素杯等）、吃防御区、基础区含队友固定拐 |
| 剧变反应 | 超载/超导/感电/扩散/绽放/燃烧/碎冰 | 无传统增伤区、无防御区、不吃队友基础区拐；不可暴击（默认） |
| 月曜/星烁反应 | 队伍有月曜/星曜角色时替换对应反应（月感电/月绽放/月结晶、星超导/星扩散），或角色技能直接造成 | 不吃传统增伤、无视防御、可暴击、含精通反应增伤区、羽毛区特殊 |

## 一、传统直伤公式

```
伤害 = ( 倍率 × 属性 × 大权区 + 羽毛区 + 激化固定增伤 )
       × (1 + 暴击率 × 暴击伤害)
       × (1 + 传统增伤)
       × 抗性系数 × 防御系数 × 增幅系数
```

### 基础区 = `倍率 × 属性 × 大权区 + 羽毛区 + 激化固定增伤`

基础区是"角色属性转化为伤害基数"的部分，由**角色自身基础区 + 队友提供的基础区拐**构成：

- **角色自身基础区 = 属性 × 倍率**：属性=有效攻击（攻击模型）/有效防御/有效生命等（由技能结算属性决定）；倍率查 `skill_param`。
- **队友基础区拐按描述形式计算**：
  - **大权区**（倍率乘区）：描述为"伤害提高为原来的 X% / 伤害提高 X%（乘算型）"，如那维莱特天赋、宵宫战技。**多个大权区之间互相乘算**（如 200% × 220%）。
  - **羽毛区**是社区对倍率后基础伤害加算的简称，不是圣遗物羽毛给面板的固定攻击311。
- **羽毛区**（固定数值加算）：描述为"伤害提高，数值相当于 XX 的 Y%"，如申鹤冰翎、裁叶萃光。**加在白值×百分比之外**，不随大权区放大。
- **激化固定增伤** = `反应基础值 × 激化系数 × (1 + 5×精通/(精通+1200) + 激化增伤)`，超激化系数 1.15、蔓激化 1.25；未触发激化为 0。

### 暴击区（期望）

`1 + min(1,max(0,暴击率)) × 暴击伤害`；有效暴率限制在0%～100%。

### 传统增伤区

`1 + Σ(元素伤害加成、全伤加成、技能类型加成等) - 敌方减伤`。**月曜/星烁伤害不吃此区**。

### 抗性系数（分段）

```
抗性 < 0：      1 - 抗性/2
0 ≤ 抗性 < 75%： 1 - 抗性
抗性 ≥ 75%：    1 / (1 + 4×抗性)
```

### 防御系数

```
防御系数 = (角色等级+100) / [ (角色等级+100) + (怪物等级+100) × (1-减防) × (1-无视防御) ]
```

- 减防效果之间**加算**，上限 90%；无视防御之间**加算**，上限 100%（超过无收益）。
- 等级压制存在：90 级打 90 级约 0.5。

### 增幅系数（蒸发/融化）

```
增幅系数 = 增幅基础系数 × (1 + 2.78×精通/(精通+1400) + 增幅增伤)
```

- 基础系数：水打火/火打冰 = 2.0；火打水/冰打火 = 1.5。未触发增幅时系数为 1。
- 增幅增伤：魔女 4 件等。

## 二、剧变反应公式

```
剧变伤害 = ( 反应基础值 × 剧变系数 × (1 + 16×精通/(精通+2000) + 剧变增伤) + 剧变羽毛区 ) × 抗性系数
```

- **与攻击/倍率/传统增伤/暴击/防御完全无关**。
- **反应基础值**（只与角色等级有关）：

| 等级 | 70 | 80 | 90 | 95 | 100 |
|---|---|---|---|---|---|
| 反应基础值 | 765.64 | 1077.44 | 1446.85 | 1561.46 | 1674.81 |

- **剧变系数**（V5.2 增强后）：燃烧 0.25 / 扩散 0.6 / 超导 1.5 / 感电 2 / 绽放 2 / 超载 2.75 / 碎冰 3 / 烈绽放·超绽放 3
- 扩散伤害可再触发增幅反应（乘增幅系数）。
- 触发者：后手附着触发者面板生效。

## 三、月曜伤害（月感电/月绽放/月结晶）

游戏中的替换条件与App实际启用分开核对：队伍身份本身不证明本场景已启用替换。按当前能力声明资格与enabled等输入；满足条件的月曜伤害兼具：**不吃传统增伤**（如元素杯）、**无视防御**（不吃防御区）、**可暴击**。

**月曜基础系数**：月绽放 1 / 月感电 3 / 月结晶 1.6

### 直伤月曜（角色技能直接造成，标注"视为月曜反应伤害"）

```
直伤月曜 = ( 倍率 × 属性 × 月曜基础系数 × (1+月曜基础增伤)
             × (1 + 6×精通/(精通+2000) + 月曜增伤) × 月曜大权区
             + 直伤月曜羽毛区 )
           × (1+暴击率×暴击伤害) × 抗性系数 × (1+月曜擢升)
```

- 与直伤结构类似，但基础区由月曜基础系数缩放，且**无防御区、无传统增伤区**。

### 反应月曜（月感电雷暴云 / 月结晶月笼造成）

```
单人反应月曜 = ( 反应基础值 × 月曜基础系数 × (1+月曜基础增伤)
                 × (1 + 6×精通/(精通+2000) + 月曜增伤) × 月曜大权区
                 + 反应月曜羽毛区 )
               × (1+暴击率×暴击伤害) × 抗性系数 × (1+月曜擢升)

最终伤害 = 0.6×最高 + 0.3×第二高 + 0.05×第三高 + 0.05×第四高
```

- 反应月曜用反应基础值替代属性×倍率。贡献者必须满足该反应的资格与有效时窗，不是所有历史附着者；按具体反应的角色槽、权重和排序规则计算。涉及独立暴击且排序可变时，先对联合暴击结果按规则加权，再求期望，不能先按单人期望排序。
- **暴击在求和前已逐组分判定**——多组分时不能用简单期望公式，需按各组分暴击率加权算期望。
- 不随等级成长的说明：直伤月曜不随等级（属性已含成长）。

### 月曜专有乘区

| 乘区 | 说明 | 示例来源 |
|---|---|---|
| 月曜基础增伤 | 基础区乘算 | 伊涅芙天赋（至多 14%） |
| 月曜增伤 | 与精通加成同区加算 | 伊涅芙 1 命（至多 50%）、月曜队伍 buff（至多 36%） |
| 月曜大权区 | 独立乘区 | 奈芙尔天赋伪秘之帷 |
| 月曜羽毛区 | 固定数值加算 | 菈乌玛苍色祷歌、兹白太阴降、莉奈娅 1 命 |
| 月曜擢升 | 独立乘区，互相加算 | 仅五星命座，极稀有 |

**关键规则**（用户校订 2026-09-02 + 社区公式确认）：
- 月曜**不吃传统增伤**、**不吃队友提供的普通基础区拐**（羽毛区仅限月曜专属来源）。
- **月曜羽毛区（反应基础区拐）的数值不吃反应伤害加成**（精通/月曜增伤）——公式中羽毛区在精通乘区之外加算。
- **月兆与满辉**：队伍中有月兆角色（带"月兆祝赐"天赋）提升月兆等级——1 位为**初辉**、2 位为**满辉**。**满辉**时非月兆角色施放战技/爆发后的**20秒**内，按自身属性为全队提供月曜反应增伤（至多 36%）：火/雷/冰每 100 攻击 +0.9%（封顶 4000 攻击）、水每 1000 生命 +0.6%（封顶 6 万）、岩每 100 防御 +1%（封顶 3600）、风/草每 100 精通 +2.25%（封顶 1600）。此项自身不叠加，后次非月兆E/Q刷新持续时间并更新提供者；不能把多人此项相加、相乘或无据取最高，也不能据此排斥其他独立月曜Buff。
  原始配置中的攻击／防御／精通有NONEXTRA读取，最大生命另列；具体被排除来源须核实。提供者更新不自动证明数值在施放时快照或全程动态，应查证取样语义，未知则显式假设并保留影响，不能按最终面板一概二次转化。
- 对应元素暴击 buff（如裟罗 C6、五郎 C6）可作用于月曜伤害。

## 四、星烁伤害（星超导/星扩散）

具体星烁替换/伤害需符合该机制状态及当前App显式启用/资格条件，不能只因队伍有某类角色就声称已执行。结构与月曜平行：

**星烁基础系数**：
- 直伤星超导：层数 0 时 1；1–12 层时 `0.05×层数 + 1.4`；>12 层时 2（处于辉映·星超导状态；不在状态时按 1 计）
- 直伤星扩散 1；反应星扩散·冰 2 或 3（按风旋等级系数）；反应星扩散·风 0.75

```
直伤星烁 = ( 倍率 × 属性 × 星烁基础系数 × (1+星烁基础增伤)
             × (1 + 6×精通/(精通+2000) + 星烁增伤) × 星烁大权区 + 直伤星烁羽毛区 )
           × (1+暴击率×暴击伤害) × 抗性系数 × (1+星烁擢升)

反应星烁：单人结构以反应基础值替代属性×倍率；贡献者、元素角色槽、有效时窗及权重/排序按具体分项规则，不等同于全局排序。星扩散等专用槽位见 reactions.md 和当前执行合同。
```

- 星超导：目前只有直伤型（冰 C / 雷 C 各按自身元素结算），无反应伤害。
- 反应星扩散·冰可再触发融化（×1.5 基础系数增幅，精通/增幅增伤只看唯一伤害源角色）。
- 极星辉域提供的冰/雷普通增伤：0 层 20% / 1–12 层 28%+层数×1% / >12 层 40%。

## 五、攻击区（传统直伤的属性来源）

```
有效攻击 = (角色基础攻击 + 武器主属性攻击) × (1 + 百分比攻击加成) + 固定攻击加成
```

- **白值** = 角色基础攻击（含 100 级提升）+ 武器主属性攻击。**百分比攻击只乘白值**——最常见错误来源。
- **白值收益稀释**（用户校订）：白值差异的独立收益只覆盖自身基础区；队友固定基础区拐（羽毛区）加在白值×百分比之外，与白值无关——固定拐越多，武器白值差贡献越小（详见 `artifacts.md`）。
- **非攻击结算**：防御/生命/精通模型技能把"有效攻击"换成对应属性的有效值（同理分白值与加成），计算前先确认技能结算属性。

## 六、报告口径

- 区分：非暴击伤害 / 暴击伤害 / 期望伤害。默认报期望，另列暴击大数字。
- 多段技能仅在结算属性、Buff、目标状态、取样、暴击/反应条件等完全一致，且不丢失逐次触发、附着、资源或次数消费时，才可数值合并；否则逐事件计算。
- 显式使用本任务角色/目标等级、抗性、命中条件和受支持约束。简化只在有依据的估算范围内声明，不能自动忽略等级差、未命中或被拒绝动作；通用数值结果不证明游戏机制完整。

## 七、快速检查清单

1. **先判定伤害类型**：直伤 / 剧变 / 月曜 / 星烁？套对应公式。
2. 技能结算属性是什么（攻击/防御/生命/精通）？
3. 白值算对了吗（角色+武器，百分比只乘白值；羽毛拐加在白值×百分比之外）？
4. 触发反应吗？增幅/激化/剧变/月曜/星烁走对应分支。
5. Buff 归哪个乘区（大权/羽毛/增伤/月曜增伤/擢升）？同区加算了吗？
6. 月曜/星烁伤害别误加传统增伤区与防御区。
7. 反应月曜/星烁多组分：暴击逐组分判定，加权 0.6/0.3/0.05/0.05。
8. 暴击按期望还是大数字报告？
9. 双方等级、减防（≤90%）、无视防御（≤100%）、目标抗性代了吗？
10. 快照/ICD/专属机制影响本次计算吗（查 annotation）？
