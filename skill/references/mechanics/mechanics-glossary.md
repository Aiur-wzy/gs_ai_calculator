# 术语表与常见机制速查

> 适用：需求理解时对齐用户术语、快速定位机制概念。按主题分组，每条一句话定义 + 计算关联。

## 一、基础术语

| 术语 | 含义 | 计算关联 |
|---|---|---|
| 白值 | 角色基础攻击 + 武器主属性攻击 | 一切百分比攻击加成只乘白值 |
| 绿字 | 面板中白值之外的加成部分 | 面板核对时分层来源 |
| 乘区 | 伤害公式中相互独立相乘的部分 | 同区加算、跨区乘算 |
| 稀释 | 同一乘区堆得越多边际收益越低 | 词条分配的核心原理 |
| 期望伤害 | 计入暴击率的长期平均伤害 | 默认报告口径，区别于暴击大数字 |
| DPS | 每秒伤害 = 循环总伤 / 循环时长 | 时长与伤害同等重要 |

## 二、机制术语

| 术语 | 含义 | 计算关联 |
|---|---|---|
| ICD | 附着等事件的内部限制；常见timer-counter不等于两条件互相重置，组别与特殊规则须查证 | 见[反应与ICD](reactions.md#六icd内置冷却)，不能按普攻/E/Q名称猜共享 |
| 元素量（U） | 附着的元素强度单位（弱 1U/强 2U/超强 4U） | 反应次数与残留判断 |
| 快照（Snapshot） | 指定属性/收益在有据时点取样；不同部分可采用不同规则 | 不等于锁整份面板或敌方状态；按组件核实 |
| 动态结算 | 实时按当前面板结算 | Buff 覆盖窗口必须全程 |
| 前摇/后摇 | 技能动作前后的硬直时间 | 循环时长构成 |
| 取消 | 用冲刺/跳跃/切人打断后摇 | 压缩循环时长 |
| 产球 | 技能命中产出的元素微粒 | 能量账基础 |
| 同色/异色充能 | 同元素微粒回能效率高，异色约 1/3 | ER 需求计算 |
| ER 达标 | 在已声明收入/时点/假设下，每次需能动作前资源足额 | 收益上限与能量足额分别核实；不由面板ER单独证明 |
| 脱手技 | 满足条件时角色结束施放/离场后仍可继续的效果 | 施放仍占用动作；后续命中可与其它动作并行，存续条件另核 |

## 三、配装术语

| 术语 | 含义 | 计算关联 |
|---|---|---|
| 词条数（rolls） | 副词条强化次数的质量计量（按平均档折算） | 圣遗物质量评估 |
| 双暴 | 暴击率 + 暴击伤害 | 配比趋近 1:2 最优 |
| 元素杯/攻击杯 | 杯子主词条选择 | 增伤区 vs 攻击区的权衡 |
| 2+2 散件 | 两个 2 件套组合 | 与 4 件套按等效词条比较 |
| 主 C / 副 C / 拐 | 站场输出 / 脱手输出 / 增益辅助 | 队伍分工，决定配装方向 |
| 反应覆盖率 | 输出中触发反应的比例（受 ICD 与附着安排限制） | 精通收益的前提 |

## 四、反应术语速查

| 术语 | 一句话 |
|---|---|
| 增幅 | 蒸发/融化，乘算放大本次伤害（1.5/2.0 × 精通加成） |
| 激化 | 草雷状态，超/蔓激化为基础伤害区加算，吃增伤暴击 |
| 剧变 | 通常以等级基础值计算，按精通、对应反应收益、抗性等结算 |
| 燃烧/冻结 | 分别涉及持续伤害/元素状态；冻结本身无直接伤害也会影响条件收益与后续反应，不能据此忽略状态 |

## 五、计算中易错点速查（拉表前自查）

1. 百分比攻击乘白值，不是乘面板总值。
2. 增幅反应吃**触发者**精通，不是附着者。
3. 剧变反应不吃攻击/增伤/暴击。
4. 激化加成是基础伤害区**加算**，不是独立乘区。
5. 只有同一伤害体系、同一作用区且可叠加的收益才同区合并；描述中的“提高/增伤”不足以决定乘区。
6. 减抗过 0 后收益减半（负抗性区）。
7. 减防分别加算后上限90%，无视防御分别加算后上限100%；两者在防御区相乘，细则见 damage-formula.md。
8. 快照与否是逐技能机制，描述不写——查 annotation。
9. 循环 DPS 要除时长，别忘了切人和动作耗时。
10. 先核每次需能动作可执行，再比较ER和输出词条收益；有ER转伤害等机制时另算收益映射，封顶不证明循环。

## 六、与数据库 annotation 的分工

- 本目录（mechanics/）：**通用规律**——所有角色共用的公式、机制原理。
- 数据库 annotation：**角色特异**——某角色的 ICD 分组、快照与否、隐藏判定等描述未写的机制。
- 采用的通用规律与角色事实共同决定当前输入。annotation不是唯一资料，也不保证完整；按角色相关目标查正文/参数/附录，缺项可研究和显式声明，不能以没有annotation阻断所有任务。

标准ICD与快照边界核对来源：[KQM ICD](https://library.keqingmains.com/combat-mechanics/internal-cooldown)、[KQM取样](https://library.keqingmains.com/combat-mechanics/snapshot-and-dynamic)，查阅2026-11-06；具体组件例外仍需当前版本证据。
