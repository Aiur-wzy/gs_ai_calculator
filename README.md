# 原神拉表 · GS AI Calculator

原神拉表是 Windows 上的队伍排轴、能量与伤害计算工具。Agent 查询资料并整理计算输入，引擎执行计算；GUI 用于查看动作、Buff 和伤害时间轴，人工审核和寻找问题。

## 当前推荐的使用方式

**当前建议通过 CLI 完成任务，使用 GPT-6.1 Sol 或能力更强的模型。GUI 的最佳用途是人工看图、审核方案、查找问题。**

1. 给能够执行本地命令的 Agent 提供独立工作目录、本版 [Skill](skill/SKILL.md) 和任务条件。
2. 让 Agent 调用 App CLI 查询、编排、计算并保存原生方案，同时说明未完成项、机制近似和计算结果。
3. 在 GUI 中打开原生方案，查看时间轴和计算报告；有疑问时让 Agent 回到 CLI 修正输入并重新计算。

应用内原生 Agent，以及 DeepSeek 在本项目复杂任务中的表现，目前仍不稳定，可能漏项、误解反馈或过早结束任务。原生对话功能保留，但暂不推荐把它作为复杂拉表的主要工作路径。模型推荐来自本项目的使用经验；任何模型输出仍需检查，计算通过也不等于游戏机制已经全部还原。

具体命令、文件角色与审核方法见 [CLI 工作流](docs/cli-workflow.md)。普通 CLI 查询和计算不自行调用模型；模型由你使用的外部 Agent 提供。

## 版本与下载

首个正式版对应 **App 0.46.0-r19 / 数据库 db-7.2.50-r6**，上游资料快照为 **7.2.50**。正式版使用独立的 Windows 用户资料目录，首次安装从空白资料开始。旧开发版程序包仅供历史参考。

- 下载和校验值以[应用发行页](https://github.com/Aiur-wzy/gs_ai_calculator/releases)及[数据库发行页](https://github.com/Aiur-wzy/gs_ai_calculator_db/releases)实际提供的附件为准。小安装器可以安装程序和配套数据库，也可以只装程序、稍后补装数据库。
- 当前不做 Windows EXE 签名，启动时可能出现发布者或安全提示。下载后按发行说明核对来源及文件校验值。
- 在线安装和更新按已签名的兼容组合选择版本。[安装指南](docs/install.md)介绍小安装器、独立程序 ZIP 和离线安装方式。[版本记录](CHANGELOG.md)列出变更。
